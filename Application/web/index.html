Calibrate voltage and current

  1. Set up: use a steady AC input at your operating frequency. Measure the AVR AVCC supply relative to GND.
  2. Compare: enter the actual load AC RMS from a trusted meter or scope, before conditioning. Leave an unused channel blank.
  3. Capture: wait for 8 stable captures, then hold the averaged capture. For a wider range, record points at low, middle and high amplitudes.
  4. Apply: download the header, replace calibration.h in Microchip Studio, rebuild and flash the normal AVR firmware. Verify at another amplitude.

The table describes the conditioned signals at PC0 / pin 23 (voltage) and PC1 / pin 24 (current), relative to GND. Use the scope’s AC RMS measurement, excluding DC offset. The reference fields describe the load, before conditioning. Enter RMS values measured directly; peak-to-peak divided by 2√2 is valid only for a sine wave. Keep the current reference blank while its input is flat.

To apply: replace calibration.h in the AVR project, build, then flash the AVR. The ESP32 cannot write AVR settings over the existing transmit-only firmware. Power scaling updates automatically; gain calibration does not correct phase error. Changing AVCC alone changes ADC-pin voltage conversion; load gains change only when you supply load references. Averaging improves repeatability, not the 10-bit ADC resolution. The 20.8 ms block may contain partial cycles; calibrate at the intended frequency and verify elsewhere.
