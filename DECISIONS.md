# Design Decisions

Every real decision gets an entry, written the day we make it. Takes two minutes and saves an argument in October.

The point of this file is the final interview. "Why did you choose X" gets asked, and this is how all four of us give the same answer about something we settled in August.

Anything still `OPEN` past its "needed by" date is a problem worth raising at standup.

```
## DECIDED Shunt resistor value
Needed by:  before Lab 3, the differential amp gain depends on it
Owner:      Everyone
Decided:    0.5 ohm, made from two 1 ohm 0805 in parallel
Why:        Max current is 595 mA RMS at 7.5 VA and 12.6 V. Lab 1 caps shunt
            dissipation at 200 mW, and 0.5 ohm gives 177 mW. Splitting it
            across two 0805s puts 88 mW in each, inside the 125 mW package
            rating. Gives 421 mV peak to amplify.
Rejected:   1 ohm, better signal but 287 mW, over the lab limit and over the
            package rating even split two ways. Current transformer, no phase
            error correction needed but bigger, costlier and not in stock.
Date:       31/07/2026
```

# Firmware

## DECIDED Replace external mode LEDs with display suffixes
Needed by:  local display integration
Owner:      Team 34
Decided:    Remove ESP32 indicator GPIO setup/writes. Use the AVR's right-most
            digit (DS1) for U/A/P/E, leaving three digits for V/A/W/Wh.
            Adjust decimals automatically; UART current stays in mA and mode
            packets remain available as website metadata.
Why:        User requested a letter on the existing display instead of wiring
            four GPIO-driven LEDs. U is legible on seven segments; A uses amps
            so 400 mA is correctly labelled 0.40A.
Rejected:   Showing 400A for a 400 mA load; losing the suffix on overflow.
Date:       18/10/2026

## DECIDED Scope telemetry and calibration header
Needed by:  dashboard integration and scope comparison
Owner:      Team 34
Decided:    Send 32 contiguous V/I sample pairs at 104 us per point, AVR energy
            totals, and full-block raw ADC statistics over UART. Keep reference
            and channel gains in calibration.h, generated by the dashboard or
            edited directly. Rebuild/reflash AVR to apply; derive power scaling
            from both gains. Serve deterministic gzip HTML from ESP32 flash.
Why:        Actual captures expose distortion and flat/clipped channels. Raw
            RMS, DC and peak-to-peak support scope comparison without assuming
            a sine. One header avoids inconsistent power and waveform gains.
Rejected:   Synthetic live waveforms; gain calibration on a flat/clipped input;
            remote AVR writes without a receiver/bootloader protocol.
Date:       18/10/2026

## DECIDED Display digit order verified on hardware
Needed by:  display integration
Owner:      Team 34
Decided:    DS1 is the right-most digit, DS4 is the left-most. Scan logical
            least-significant digit first using DS1, DS2, DS3, DS4.
Why:        Bench readings were reversed: 400 appeared as 004 and 13.70 as
            073.1. Reversing digit enables also places the decimal correctly.
Rejected:   Reversing numeric strings or moving decimal bits separately.
Date:       18/10/2026

## DECIDED Single AVR project and ESP32 display indicators
Needed by:  hardware triage and final integration
Owner:      Team 34
Decided:    Retain the newer RMS-current implementation as
            Software/Joule_observer/Joule_observer.atsln (ATmega328PB, 2 MHz).
            Remove the duplicate Testing and placeholder UART AVR projects.
            USART0 sends $D,0..3 on display changes and every 250 ms.
            ESP32 LED1/2/3/4 use GPIO25/26/27/32 for V/I/P/E respectively.
            Keep UART2 RX on GPIO16; the schematic's RXD0 label was incorrect.
Why:        User requested one AVR project and mode LEDs driven by ESP32.
            The retained implementation removes each ADC channel's DC offset.
            Explicit mode messages follow the AVR scan instead of a second timer.
Rejected:   Independent ESP32 mode cycling, which drifts or resets out of sync.
Date:       18/10/2026
